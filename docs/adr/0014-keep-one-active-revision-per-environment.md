# Keep one active revision per environment

An environment has one active application revision outside a deployment transition. Blue-green deployment may temporarily prepare and verify a candidate beside the active revision, but activation ends with one selected revision. Deployments to the same environment are serialized, while concurrent isolated testing uses separate environments. A shared environment may additionally expose an optional expiring lease; overriding it requires explicit acknowledgement and an audit record but does not create permanent ownership. This keeps shared-environment history and behavior unambiguous rather than turning one environment into an implicit multi-tenant revision host.
