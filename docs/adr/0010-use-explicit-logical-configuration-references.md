# Use explicit logical configuration references

Configuration is composed from explicitly referenced logical documents in an explicit order. Teams may store those documents in one physical file or many files, but Provision does not infer meaning from filenames or automatically scan directories. Maps merge by key, lists replace, and repeated scalar values require an intentional override. Provision exposes the resolved configuration and value provenance, and rejects all detectable contradictions before making changes. This avoids hidden configuration appearing because a file was renamed, moved, added, or ambiguously combined.
