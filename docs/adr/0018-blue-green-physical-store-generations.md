# Apply blue-green to physical store generations

A database, cache, or object store remains one logical component while blue-green work temporarily maintains active and candidate physical generations. Required mode prepares a separately addressable candidate, synchronizes or rebuilds it as appropriate, verifies it, switches authority, and retains the previous generation for a declared rollback window. Store transitions are driven by environment configuration revisions and cover upgrades, upsizing, storage changes, and implementation migrations; application-defined schema migrations remain a separate concern. This avoids forcing availability-sensitive store changes into in-place mutation while preserving one authoritative store after handoff.
