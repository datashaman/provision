# Issue tracker: GitHub

Issues and specs for this repo live in GitHub Issues. Use `gh` from this repository; its `origin` remote identifies `datashaman/provision`.

Create, read, list, comment on, label, and close issues with the corresponding `gh issue` commands. When a skill says to publish to the issue tracker, create a GitHub issue; when it says to fetch a ticket, read that issue and its comments.

## Pull requests as a triage surface

PRs as a request surface: no. Triage issues, not external pull requests. This flag can be changed here later.
