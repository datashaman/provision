# Curate an AWS service portfolio

The initial AWS portfolio is RDS for PostgreSQL, ElastiCache for Valkey, SQS, S3, EventBridge Scheduler, ECS or Fargate, Lambda versions and aliases, ALB, API Gateway HTTP and WebSocket APIs, Route 53, and ACM. Native ECS blue-green and Lambda aliases provide the primary executable handoff mechanisms. Each adapter still publishes narrow capability checks, because selecting a service name alone does not prove a workload or store transition can meet its required guarantees.
