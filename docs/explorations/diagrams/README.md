# Diagram status

These diagrams are conceptual explorations. They visualize requirements and possible boundaries; they are not approved technical architecture.

Some labels use the earlier `cache` role. The agreed model now uses a `key-value store` with an explicit Store Data Role; see [ADR 0068](../../adr/0068-model-key-value-stores-with-explicit-data-role.md).

- `provisioning-platform.html`: deployment-flow exploration.
- `deployment-profile-model.html`: environment and implementation-selection exploration.
- `first-class-components.html`: fixed component vocabulary exploration.
- `blue-green-release.html`: blue-green behavior exploration.
